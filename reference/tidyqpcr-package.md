# tidyqpcr: Quantitative PCR Analysis with the Tidyverse

This package is for reproducible quantitative PCR (qPCR) analysis using
packages from the tidyverse, notably dplyr and ggplot2. It normalizes
(by ddCq), summarizes, and plots pre-calculated Cq data, and plots raw
amplification and melt curves from Roche lightcycler machines. It does
NOT (yet) calculate Cq data from amplification curves.
